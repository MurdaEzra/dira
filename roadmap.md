# DIRA roadmap

## Phase 1 — foundations (seeded data)
- [x] Design system (palette, light/dark/high-contrast, text scale, readable font, reduced motion)
- [x] English + Swahili UI
- [x] Onboarding + accessibility profile (editable in Profile)
- [x] Home map (search, locate, layers, category chips, shape-coded pins, bottom sheet)
- [x] Discover (filters, min confidence, sort by fit then distance)
- [x] Place detail (feature checklist with status + confidence + last confirmed)
- [x] Confidence scoring + fit score with tests

## Phase 2 — routing
- [ ] Lovable Cloud tables + seed (places, features, barriers)
- [ ] OpenRouteService wheelchair routing with avoid_polygons + seeded fallback routes
- [ ] 3 route options, segment colouring, turn-by-turn, live reroute

## Phase 3 — reporting + AI
- [ ] 3-tap barrier report, offline queue, photo upload
- [ ] AI photo analysis (strict JSON), privacy blur, verification flow, place photo gallery

## Phase 4 — voice
- [ ] Mic on every screen, intents, spoken + vibration cues

## Phase 5 — community + ops
- [ ] Contributor profiles, badges, leaderboard, impact dashboard, export
- [ ] Partner portal (claim place), admin moderation, PWA/offline
